## Repository Setup

## Challenges Faced

During the initial push, Git rejected the changes because the remote repository already contained a separate commit. I resolved this by merging the local and remote histories. A README merge conflict also occurred, which I fixed manually.

This setup helped me understand the basic Git workflow, repository management, and the importance of maintaining an organised project structure.
