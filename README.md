# The Digital Detective

## Project Overview

Welcome to my Digital Detective project!

This repository contains my independent learning assignment, where I explore different areas of computing through a series of practical missions.

The project covers computer fundamentals, terminal operations, operating systems, program execution, number systems, Git and GitHub, and computer networking.
