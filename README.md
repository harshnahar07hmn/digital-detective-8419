## How to Run the Python Number Converter

To run the decimal-to-binary and hexadecimal converter created in Mission 5:

1. Open Terminal and navigate into the Mission 5 folder:
   ```bash
   cd mission-05-numbers-data
   python3 number_converter.py
2. Enter any positive decimal integer when prompted to see its binary and hexadecimal   values.
