# Mission 1 – Know Your Computer

## Mission Objective

Understand how a computer receives input, processes information, produces output and stores results. Identify hardware, software and everyday computer-based systems.

---

## Task 1.1 – Trace One Activity Using IPOS

**Activity:** Opening Microsoft Word, typing an assignment and saving it.

| Stage | What happens in my example? | Hardware / Component |
|---|---|---|
| Input | Text is entered using the keyboard. | Keyboard |
| Processing | The computer processes the keystrokes and updates the document. | CPU and RAM |
| Output | The document appears on the screen. | Screen / Monitor |
| Storage | The document is saved on the SSD or cloud storage. | SSD / Cloud storage |

### Explanation

When I open Microsoft Word and type my assignment, the keyboard sends input to the computer. The CPU processes the keystrokes and RAM temporarily holds the data being used. The updated document appears on the screen. Finally, I save the document so that it can be accessed later from the SSD or cloud storage.

## Task 1.2 – Identify Hardware and Software

| Item / Software Name | Hardware or Software? | Software Type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Used to enter text |
| RAM | Hardware | Not applicable | Temporarily holds data currently being used |
| Monitor | Hardware | Not applicable | Displays visual information |
| SSD | Hardware | Not applicable | Stores files and applications |
| macOS | Software | Operating system software | Manages hardware and system resources |
| Google Chrome | Software | Application software | Performs tasks such as browsing the internet |
| Antivirus | Software | Utility software | Helps maintain and protect the system |
| Visual Studio Code | Software | Application software | Used to write and edit code |
